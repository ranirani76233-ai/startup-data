# 🚀 Startup Analytics Dashboard

A professional Streamlit dashboard for startup ecosystem analytics.

## Features

- Interactive KPIs
- Industry Analytics
- Regional Insights
- Funding Analytics
- AI Insights
- Plotly Visualizations

## Installation

```bash
git clone https://github.com/yourname/startup-analytics-dashboard.git

cd startup-analytics-dashboard

pip install -r requirements.txt

streamlit run app.py
```

## Tech Stack

- Python
- Streamlit
- Plotly
- Pandas
- Scikit-Learn
